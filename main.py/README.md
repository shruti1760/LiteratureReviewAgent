## Literature Review Agent

An agentic literature review assistant built with PydanticAI.

## Goal

Build a research assistant that can:

- Interpret a literature-review task
- Extract structured information from research papers
- Analyze papers for similarities, differences, and research gaps
- Generate a structured literature review

## Architecture

PDF → Orchestrator → Planner → Reader → Analyzer → Writer

## Tech Stack

- Python
- PydanticAI
- Pydantic
- PyMuPDF
